# SoftGrowTech Personal Portfolio

A responsive personal portfolio website created for **SoftGrowTech Web Development Task 1** using only HTML, CSS and JavaScript.

## Project

**Project 1 — Personal Portfolio Website**

### Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts

### Features
- Responsive navigation
- Mobile menu
- Hero section
- About section
- Skills section
- Projects showcase
- GitHub and live project links
- Contact section with frontend form validation/demo message
- Responsive layout for mobile, tablet and desktop
- Smooth scrolling

## Run Locally

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

For the best development experience, use the VS Code Live Server extension.
